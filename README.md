# 🎯 AI Recruiting Screener

AI-powered recruiting tool that screens candidates and generates ready-to-send reports.

## Features

* **CV Screening** — Upload CV + phone screen notes, get a verdict, fit score (0–100), and multidimensional breakdown (Skills / Seniority / Industry / Trajectory)
* **Career DNA** — Analyzes candidate trajectory: Builder vs Scaler pattern, promotion velocity, stage history, and hidden gems
* **Slack Client Presentation** — Generates a ready-to-paste Slack message to present the candidate to the hiring manager
* **BambooHR Note** — Structured ATS note with verdict, strengths, concerns, and next step
* **Boolean Search Generator** — Auto-generates LinkedIn boolean search strings from the job description
* **Pipeline Kanban** — Drag-and-drop board to track candidates across sourcing, screening, interview, offer, and hired stages
* **Interview Guide** — Pre-interview question guide tailored to each candidate's gaps
* **Post-Interview Analysis** — Analyzes interview transcript and generates a present/reject decision with reasoning
* **Sourcing Autopilot** — Batch enrichment via NinjaPear API: paste a Sales Nav CSV, get profiles auto-fetched and screened
* **Rejection Pattern Analysis** — Learns from client rejections to recalibrate screening criteria
* **Report Download** — Export full candidate report as .txt
